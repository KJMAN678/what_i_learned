## MCP本を読んだ

- MCP（Model Context Protocol）の全体像
    - ホスト・クライアント・サーバーの 3 つの役割に分かれる
    - サーバーは tools・resources・prompts を公開する
- 通信方式
    - 手元で動かすなら stdio が手軽
    - リモートで動かすなら Streamable HTTP を使う

## 猫見守りの開発環境を整えた

- Docker Compose でアプリとデータベースをまとめて起動するようにした
    - コンテナ間はサービス名で名前解決できる
- 画像の保存先は本番と同じく Amazon S3 を想定している
    - 手元では S3 互換のエミュレーターで代用する

```yaml
services:
  app:
    build: .
    ports:
      - "8000:8000"
    depends_on:
      - db
  db:
    image: postgres:17
```

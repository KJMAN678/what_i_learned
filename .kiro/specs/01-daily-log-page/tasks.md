## Implementation Notes
- サンドボックスでは uv の既定キャッシュに書けないため `UV_CACHE_DIR=$TMPDIR/uv-cache` を付けて実行する。PyPI への接続には pypi.org と files.pythonhosted.org の許可が要る
- `python -m wil.records` を content/ が無い状態で引数なし実行すると exit 0（検査対象なし）。4.1 のビルド手順で content 不在時の扱いを決める

# Product Overview

自分の日々の学習成果を Markdown のログとして書き、GitHub Pages で公開する個人サイト。主目的は「後で自分が見返して調べ直せること」、副目的は「自分が何を学んでいるかを人に紹介できること」。

## Core Capabilities

- 1日 = 1ページの学習ログを手書き（または Claude と壁打ち）で作り、push するだけで公開される
- 一覧・タグ・全文検索で過去のログを探せる
- 「ある技術をいつ学んだか」を時系列で辿れる
- 過去の知見を MCP 経由で Claude から引き出せる
- 学習の偏りを可視化し、次に学ぶとよい領域を提案する

## Target Use Cases

- その日に学んだこと・気になった技術情報を、手間をかけずに記録する
- 今困っていることに関連する過去の知見を、Claude との作業中に呼び出す
- 自分の学習履歴を他人に見せる

## Value Proposition

- 書く手間が最小（必須項目を増やさない、ビルドが壊れにくい）
- 公開前提のため、意図しないファイルや秘密情報が公開されない仕組みを持つ

## Anti-goals

- 記録の手間を増やすこと（必須 frontmatter の追加、厳しすぎる書式）
- コメント、CMS、アクセス解析、多言語対応、Web からの編集
